# K1: class-level detection of one-way transitions

Pre-registered 2026-10-25, before any measurement. Protocol: `prereg/common.md`.

## Data (first available, in this order)
1. Something-Something v2, official validation split. Every clip whose template maps to one-way or reversible under the rule below is used.
2. RoboLab (host 84). One-way = object left its support after robot contact (certified). Reversible = matched episodes from the same tasks where it did not.

The dataset used is recorded in RESULTS.md together with the date access arrived.

## SSv2 class mapping rule (fixed now; the resulting table is committed before K1 runs)
The rule is applied by script to the official template strings. No clip is labelled by hand.
- One-way: template contains tear, pour, break, spill or crush, or contains "roll" together with "off".
- Reversible: template contains moving, pushing, pulling, rotating, or lifting/putting down.
- Excluded, and listed in the table with the reason:
  - template starts with "Pretending"
  - template contains "almost", "but" or "fail"
  - template matches both lists
  - template contains fall, drop, "off of" or "over" without matching the one-way list
- Templates that contain rotating, or another symmetric motion, are tagged `symmetric`. They are included in the main test and also reported separately.

## Motion matching
1. Each one-way clip, in a random order with seed 0, is paired greedily and without replacement with the unused reversible clip whose F is nearest, provided it lies within ±10 % of the one-way clip's F.
2. Unmatched clips are dropped, and their count is reported.
3. If fewer than 50 pairs survive, K1 is inconclusive (neither pass nor fail) and is reported as such.

## Metrics, reported for each model
- AUROC(A), with one-way as the positive class and higher A predicting one-way. The direction is fixed and is never flipped.
- AUROC(F) on the same pairs. As a deliberately strong baseline it is taken as max(AUROC, 1 − AUROC).
- Δ = AUROC(A) − AUROC(F), with a paired bootstrap CI over pairs.
- YoCausal statistic: the fraction of clips with mean e_b > mean e_f (raw), reported per class group, for every model.
- On LTX-Video this statistic is computed from denoising loss (L_rev > L_fwd), which is YoCausal's own measure. That row is the baseline. Its AUROC(A) and Δ are reported under the same rule, and AUROC(V-JEPA) − AUROC(LTX) gets a paired CI.

## Pass rule (per model)
**Pass** if all three hold on the primary statistic:
- Δ ≥ 0.10
- the 95 % CI of Δ excludes 0
- AUROC(A) ≥ 0.70

**Fail** otherwise.

K1 passes at the project level if at least one V-JEPA model passes. LTX-Video does not count toward this; see `prereg/common.md`. The number of passing models out of 3 is always reported.

If K1 fails on every model, the project stops and a negative note is written.

## Reported alongside the pass rule (does not change pass/fail)
- Secondary statistics: max a, and the raw versions.
- SSv2 only: AUROC(A) after regressing A on [camera motion, clip length] by ordinary least squares over all matched clips.
- If the pass holds only without this regression, that is flagged in DECISION.md.
- Clip length is reported as a covariate.
- Per-class AUROC, with the `symmetric` group shown separately.
- Number of clips removed by each filter.
